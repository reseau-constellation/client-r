# Prépare le nom d'une fonction Constellation à être envoyé par WebSocket

Prépare le nom d'une fonction Constellation à être envoyé par WebSocket

## Usage

``` r
préparerNomFoncMessage(nomFonction)
```

## Arguments

- nomFonction:

  Le nom de la fonction en format vecteur

## Value

Le nom formatté en liste si la longeur \> 1, sinon le vecteur original
