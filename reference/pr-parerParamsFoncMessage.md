# Prépare les paramètres d'une fonction Constellation à être envoyés par WebSocket

Prépare les paramètres d'une fonction Constellation à être envoyés par
WebSocket

## Usage

``` r
préparerParamsFoncMessage(paramètres)
```

## Arguments

- paramètres:

  La liste des paramètres

## Value

Soit les paramètres eux-mêmes, soit, s'ils sont vides, un \`data.frame\`
vide
