# Package index

## All functions

- [`Client`](https://reseau-constellation.github.io/client-r/reference/Client.md)
  : Un client Constellation.
- [`avecClient()`](https://reseau-constellation.github.io/client-r/reference/avecClient.md)
  : Exécuter du code dans le contexte d'un client Constellation, et
  fermer le client par la suite. Nécessite qu'un serveur Constellation
  soit déjà activé sur le \`port\` spécifié.
- [`avecClientEtServeur()`](https://reseau-constellation.github.io/client-r/reference/avecClientEtServeur.md)
  : Exécuter du code dans le contexte d'un client Constellation, et
  fermer le client et le serveur par la suite.
- [`avecServeur()`](https://reseau-constellation.github.io/client-r/reference/avecServeur.md)
  : Exécuter du code dans le contexte d'un serveur Constellation, et
  fermer le serveur par la suite.
- [`donnéesNuéeÀTrame()`](https://reseau-constellation.github.io/client-r/reference/donn-esNu-e-Trame.md)
  : Transforme des données de nuée de format Constellation en format de
  trame de données tibble R.
- [`donnéesTableauÀTrame()`](https://reseau-constellation.github.io/client-r/reference/donn-esTableau-Trame.md)
  : Transforme des données de tableau de format Constellation en format
  de trame de données tibble R.
- [`installerConstellation()`](https://reseau-constellation.github.io/client-r/reference/installerConstellation.md)
  : Installer Constellation sur votre système. Nécessite Node.js
  (https://nodejs.org/fr) et pnpm (https://pnpm.io/)
- [`lancerServeur()`](https://reseau-constellation.github.io/client-r/reference/lancerServeur.md)
  : Lancer un serveur Constellation local
- [`obtVersionServeur()`](https://reseau-constellation.github.io/client-r/reference/obtVersionServeur.md)
  : Obtenir la version installée du serveur Constellation
- [`préparerNomFoncMessage()`](https://reseau-constellation.github.io/client-r/reference/pr-parerNomFoncMessage.md)
  : Prépare le nom d'une fonction Constellation à être envoyé par
  WebSocket
- [`préparerParamsFoncMessage()`](https://reseau-constellation.github.io/client-r/reference/pr-parerParamsFoncMessage.md)
  : Prépare les paramètres d'une fonction Constellation à être envoyés
  par WebSocket
- [`résoudreNomFonction()`](https://reseau-constellation.github.io/client-r/reference/r-soudreNomFonction.md)
  : Résout le nom de la fonction en séparant ses composantes.
- [`résoudreTypeFonction()`](https://reseau-constellation.github.io/client-r/reference/r-soudreTypeFonction.md)
  : Essaie de deviner de quel type est une fonction Constellation.
